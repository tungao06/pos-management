## 2. การตัดสินใจระหว่างทำ (ที่ไม่ได้อยู่ในแผน)

1. **ต้นทุนต่อแก้วปัดเศษครั้งเดียว** จากผลรวม BigInt (ไม่ปัดทีละวัตถุดิบ) → ตรง Excel **ทุก 360 สูตรแบบเป๊ะ** (แผนเผื่อ ±2 สตางค์ แต่ spec §8 กำหนด ±1) · มี `lineUnitCostSatang` ตาม §4.2
2. **ก่อนมีของเข้าครั้งแรก ต้นทุนเฉลี่ย = ต้นทุนมาตรฐาน** (§4.4) — `initialCostState` / `rebuildCostState(movements, standardCostUsat)` · seed ใส่ต้นทุนมาตรฐานของเบสและชุดบรรจุภัณฑ์เป็นค่า roll-up จาก BOM (เดิมเป็น 0)
3. **เงินสดคืนจากการยกเลิกบิลนับครั้งเดียว** — อยู่ใน `cashRefundsSatang` เท่านั้น · `paidOutSatang` = จ่ายออกที่คนบันทึกเองเท่านั้น (แผน 3/7 ต้องตัดแถว PAID_OUT อัตโนมัติจากการ void ออกตอนรวมยอด)
4. `verifyChain` เมื่อ chainSeq ขาด รายงาน `brokenAtChainSeq` = event ตัวแรกที่เจอหลังช่องว่าง (reason ระบุเลขที่หาย)
5. แฮช event ปฏิเสธ object ที่ไม่ใช่ plain object (Date/Map/Set) — ต้องแปลงเป็น string ก่อนใส่ payload
6. มีเทสต์กันลืม: seed JSON ที่ commit ต้องตรงกับผลของ parser · `MovementKind`/`ItemKind` ใน domain กับ contracts ต้องเป็น type เดียวกัน
7. ไม่ได้ push ขึ้น GitHub ตาม Task 13 (ต้องถามก่อน) — รัน CI ขั้นตอนเดียวกันในเครื่องผ่านแล้ว

## 4. เรื่องเล็กที่พักไว้ (ทำเมื่อถึงแผนที่ใช้)

- `priceFor` คืน `undefined` เมื่อไม่มีราคา → แผน 3 ควรมี `requirePrice` ที่ throw (ห้ามขายของไม่มีราคา)
