# แผน 4 (pos-stock) — คำถามถึงเจ้าของก่อนเริ่มทำ

สถานะ: ✅ **เจ้าของตอบครบทุกข้อแล้ว (Q4-1 – Q4-16 · Q4-11 รวมเข้า Q4-10 แล้ว) — ตามแนะนำทุกข้อ 21 ก.ย. 2026 · บันทึกเป็น D56** ใน [บันทึกการตัดสินใจ](../../design/00-บันทึกการตัดสินใจ.md) แล้ว · แผน [2026-09-17-04-pos-stock.md](2026-09-17-04-pos-stock.md) เขียนตาม **ค่าแนะนำ** ทุกข้อไว้แล้ว จึงตรงกับคำตอบพอดี ไม่ต้องแก้จุดใดก่อนเริ่ม Task 1 · ปรับตาม pre-review ของแผน (21 ก.ย.): เพิ่ม Q4-13 – Q4-15 · เขียน Q4-2 / Q4-3 / Q4-6 ใหม่ · รวม Q4-11 เข้า Q4-10 · Q4-16 (ยืนยันการแก้สเปค T4-1/T4-2 + ขอบเขต invariant 7) ถามในแชทระหว่างทำและตอบว่า "ตามแนะนำ" แล้วเช่นกัน

กติกา: เรื่องที่ spec และ D1–D55 ตัดสินแล้ว **ไม่ถามซ้ำ** (ดูหัวข้อ "ตัดสินใจเชิงเทคนิค" และ "ไม่ถาม เพราะตัดสินแล้ว" ท้ายไฟล์) · แต่ละข้อมีตัวเลือก + **ค่าแนะนำ** + เหตุผล · คำถามใหม่ที่เกิดระหว่างทำให้เพิ่มท้ายไฟล์เป็น Q4-16 เป็นต้นไป แล้วหยุดรอคำตอบก่อนทำ task ที่เกี่ยวข้อง

## ไม่ถาม เพราะตัดสินแล้ว

- ใครทำงานสต็อกได้ → ทุกคน (spec §5) · ไม่ต้อง PIN
- นับสัปดาห์ละครั้ง นับเป็นหน่วยซื้อ (D20) · ยอดยกมานับครั้งแรกทั้งหมด → OPENING ที่ราคาตั้งต้น (D30, D35 — วิธีบังคับอยู่ใน Q4-13)
- ของไม่นับสต็อก: น้ำแข็ง น้ำ น้ำดื่มถัง เกลือ (D29) · เบสติดลบไม่บล็อกการขาย (D28, spec §4.2)
- ต้นทุนถัวเฉลี่ยเคลื่อนที่ · ก่อนมีของเข้าใช้ต้นทุนมาตรฐาน (spec §4.4, D19, D34)
- เตือนราคารับเข้าต่างเกิน 10% (D47 ข้อ 3 — ตัวที่ใช้เทียบอยู่ใน Q4-15) · จุดสั่งซื้อมาจากไฟล์ร้าน (spec §3.3, §9)
- ปุ่ม "ทิ้ง" เบส = EXPIRED ทั้งก้อน ไม่มี FIFO (spec §4.6) · แจก/ชดเชยไม่ใช่บิล 0 บาท (D50 Q3-20)
- จ่ายออกเกินเงินในลิ้นชักบันทึกได้หลังยืนยัน (D54 Q3b-14) — ใบรับของที่จ่ายจากลิ้นชักใช้กฎเดียวกัน

## ช. คำถามที่เกิดระหว่างทำ (ถามในแชท 21 ก.ย. 2026)

**Q4-16** — ตารางตัดสินใจเชิงเทคนิคด้านบน (T4-1, T4-2) ระบุไว้ว่าต้องแก้ข้อความ spec ในรอบเอกสารถัดไป และ Q4-1 ระบุขอบเขตของ invariant 7 ไว้แล้ว จึงถามเจ้าของเพื่อยืนยันเป็นทางการทั้ง 3 จุด ก่อนให้ Task 3 และ Task 13 อ้างอิงได้:

1. เพิ่มตาราง `stock_adjustment` ใหม่ (T4-1) — spec §3.3 ยังไม่มีตารางนี้ (ตารางบัญชี `stock_movement` ไม่มีคอลัมน์เหตุผล และ D39 ล็อก movement kind ไว้ 11 ค่าแล้ว)
2. แก้ข้อความ spec §4.5: expected ของใบนับแช่แข็ง **ต่อบรรทัด ตอนบันทึกรายการนั้นครั้งแรก** ไม่ใช่ตอนเปิดใบนับ — ให้ตรงกับ §3.3 ที่เขียนว่า "expected = ยอดตามบัญชี ณ เวลานับ" (T4-2 — เทสต์: ขายนม 46 ml หลังเปิดใบนับ แล้วนับได้ 1 กระป๋อง → ต้องเหลือ 405 ml ไม่ใช่ 359)
3. invariant 7 ของ spec §7 ("ไม่มีธุรกรรม business_date ที่ไม่มี shift") ครอบเฉพาะบิล/เงินสด/กะเท่านั้น **ไม่ครอบงานสต็อก** (รับของ/ทำเบส/นับ/เบิกออก) — ตามคำตอบ Q4-1 (ก)
