## วิธีทดสอบบนแท็บเล็ต (เจ้าของร้านทำเอง)

**เตรียมเครื่อง dev (คอมที่รัน worktree นี้):**

```bash
cd "D:\TungAo-Project\pos-management-plan3"
winget install --id Cloudflare.cloudflared
```

เปิด Git Bash **หน้าต่างใหม่** หลังติดตั้ง (ไม่ใช้หน้าต่างเดิม — `winget install` แก้ PATH เฉพาะ shell ใหม่)

```bash
cd "D:\TungAo-Project\pos-management-plan3"
pnpm --filter @dayo/pos-spike build
pnpm --filter @dayo/pos-spike exec vite preview --port 4180 --strictPort
```

เปิด Git Bash อีกหน้าต่างหนึ่ง (ปล่อยหน้าต่างข้างบนรันค้างไว้):

```bash
cloudflared tunnel --url http://localhost:4180
```

จะได้ URL แบบ `https://<สุ่ม>.trycloudflare.com` — **สำคัญ: ต้องใช้ URL เดียวกันตั้งแต่ข้อ 1 ถึงข้อ 5 ด้านล่าง ห้ามปิด/เปิด cloudflared process ใหม่ระหว่างทำ** (ถ้า URL เปลี่ยนถือเป็น origin ใหม่ ต้องเริ่มนับจากข้อ 1 ใหม่ ห้ามบันทึกว่าข้อก่อนหน้าล้มเหลว)

**บนแท็บเล็ต (Chrome):**

1. เปิด URL `https://<สุ่ม>.trycloudflare.com` รอจนสถานะขึ้น PASS หรือ FAIL (ตัวหนังสือใหญ่สีเขียว/แดงด้านบน) → **ถ่ายภาพหน้าจอ JSON ทั้งหมด** (เลื่อนดูให้ครบถ้ายาวเกินจอ)
2. กด reload หน้า (pull-to-refresh หรือปุ่ม reload ของ Chrome) → ดูเลข `bootCount` ใน JSON ต้องมากขึ้น 1 (เช่น 1 → 2) — นี่คือ S5
3. เปิดเมนู Chrome (จุดสามจุดมุมขวาบน) → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก" → เปิดแอปจากไอคอนที่หน้าจอหลัก (ไม่ใช่จาก Chrome ปกติ) → ดูค่า S9 ใน JSON (`persisted`/`granted`) — นี่คือ S9
4. ปัดแอปทิ้งจาก recent apps (multitasking) → เปิดแอปใหม่จากไอคอน → ดู bootCount ต้องเพิ่มอีก 1 → แล้ว**รีสตาร์ตเครื่องแท็บเล็ตจริง** → เปิดแอปอีกครั้ง → bootCount ต้องเพิ่มอีก 1 — นี่คือ S10 (สำหรับข้อนี้เท่านั้น ให้สลับไปใช้วิธี `adb reverse` แทน tunnel ตามหมายเหตุด้านล่าง เพราะ URL ของ tunnel จะไม่คงอยู่หลังรีสตาร์ต)
5. เปิด URL เดียวกัน (จากข้อ 1) ในแท็บที่ 2 ของ Chrome (แท็บแรกอย่าปิด) → จดว่าแท็บ 2 ขึ้นข้อความ error อะไรที่ S1 และแท็บแรกยังกด reload ได้ปกติไหม — นี่คือ I2

**หมายเหตุสำหรับข้อ 4 (S10, ต้องรีสตาร์ตเครื่อง):** tunnel URL จะไม่คงอยู่ข้าม reboot ของคอม dev หรือแท็บเล็ต ให้ใช้วิธีสำรองแทนสำหรับข้อนี้:

```bash
# บนคอม dev ต้องมี adb (Android platform-tools) และเสียบสาย USB จากแท็บเล็ต + เปิด USB debugging
adb reverse tcp:4180 tcp:4180
```

แล้วบนแท็บเล็ตเปิด `http://localhost:4180` ใน Chrome แทน (origin นี้คงที่ และ `localhost` เป็น secure context อยู่แล้ว แม้เป็น http) — ทำข้อ 4 ด้วยวิธีนี้ **จดในผล spike ว่าข้อไหนใช้ tunnel ข้อไหนใช้ adb reverse**

**ถ้า S1 ไม่ผ่านบนแท็บเล็ต (ข้อสำรอง F1):**

