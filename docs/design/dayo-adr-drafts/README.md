# ร่าง ADR สำหรับ dayo-shop-system (จากทีม POS)

ไฟล์ในโฟลเดอร์นี้เป็น **ข้อเสนอ** (สถานะ "เสนอ") ที่ทีม POS ร่างไว้ตามสถาปัตยกรรม C1 (`../04-สเปกการเชื่อม-POS-กับ-dayo.md`) · **ยังไม่ใช่ ADR ของ dayo**

วิธีใช้
1. การตัดสินใจอยู่ใน D59–D78 ของ POS (Q40–Q53 ใน `04-*` §12) · ร่างทุกไฟล์แก้ตามคำตอบและรีวิวรอบ 1 แล้ว (`04-*` §13.2) · Q54 ตัดสินแล้ว (ทาง ก — รหัสครั้งเดียวจากเว็บ · P4 ข้อ 6) · เจ้าของรับรองสเปกแล้ว
2. เจ้าของนำร่างไปให้ **session ของ repo dayo** (`D:\TungAo-Project\line-bot\dayo-shop-system`) — ทีม POS ไม่แก้ไฟล์ใน repo นั้น
3. session ของ dayo ตรวจกับโค้ดจริง ให้เลขจริง (เลขถัดไปตอนรับเข้า — ตอนร่างนี้ ADR ล่าสุดของ dayo คือ 0047) แก้สถานะ ADR เดิมที่ถูกแก้/ขยาย และอัปเดต `docs/adr/README.md` · DATA-CONTRACT · API.md · GLOSSARY ตามกระบวนการของ dayo
4. ถ้า session ของ dayo ต้องเปลี่ยนสัญญา API (§4 ของสเปก 04) ให้แจ้งกลับ — ทีม POS แก้สเปกก่อน แล้วทั้งสองฝั่งทำตาม
