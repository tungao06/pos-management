## ส่วนที่เจ้าของทำเอง

| ขั้น | ทำอะไร | ผ่านเมื่อ |
|---|---|---|
| 1 | เปิด dayo local: Supabase local + `npm run dev:web` โดยตั้ง `API_V1_ENABLED=1` และ `POS_ORIGINS=http://localhost:4173` | หน้าเว็บ dayo local เปิดได้ |
| 2 | สร้าง API key ชื่อ "แท็บเล็ตขาย 1" ที่ `/settings/api-clients` ให้สิทธิ์ `catalog:read staff:read orders:read orders:write shift:write` แล้วนำเข้าเมนูจริงของร้าน | มี key ในมือ และเมนูจริงขึ้นบน dayo local |
| 3 | เปิดแท็บเล็ตแบบทดสอบ: ที่ repo POS รัน `pnpm --filter @dayo/pos build` แล้ว `pnpm --filter @dayo/pos preview` จากนั้นเปิด `http://localhost:4173` | หน้าตั้งเครื่องขึ้น |
| 4 | ตั้งเครื่อง: กรอก `http://localhost:<พอร์ต dev:web>/api/v1` แล้ววางกุญแจเอง | ตั้งเครื่องสำเร็จ ไม่มีแถบ "ตัวคิดราคาไม่ตรงรุ่น" |
| 5 | ขาย 20 บิลตามตารางในเอกสาร 09 (ก้อน 2) | ครบ 20 บิล |
| 6 | **กะและเงินสด:** เปิดกะ ขายเงินสด ให้บอทสร้างบิลเงินสด 3 ใบ แล้วปิดกะ (นับเงิน ออกใบปิดกะ) | หน้าปิดกะขึ้น "ตรง" (`matched`) |
| 7 | **ขายออฟไลน์ทั้งกะ:** ปิด Wi-Fi ขายหลายบิล ปิดกะ แล้วเปิดเน็ต | สถานะเปลี่ยนจาก "รอบิล" (`waiting_bills`) เป็น "ตรง" (`matched`) |
| 8 | **บิลนอกเมนู:** ขายเมนูหนึ่ง แล้วปิดเมนูนั้นบนเว็บก่อนต่อเน็ต จากนั้นแก้ที่หน้า "ส่งไม่ผ่าน" ด้วยปุ่มปิดบิลนอกเมนู (ใส่ owner PIN) | บิลถูกรับ และหน้า "ส่งไม่ผ่าน" ว่าง |
| 9 | **โปรกฎใหม่:** สร้างโปรที่พนักงานเลือกเอง 1 ตัว และโปรจำกัดจำนวนครั้ง 1 ตัวบนเว็บ แล้วขายบนแท็บเล็ต: โปรเลือกเอง 1 บิล · บิล ฿0 จากโปร (จ่ายเงินสด ใส่เหตุผล) 1 บิล · ใช้โปรจนเกินจำนวนครั้ง 1 บิล | สองบิลแรกยอดตรง บิลเกินจำนวนครั้งขึ้นในหน้า "ยอดไม่ตรงระบบกลาง" |
| 10 | รัน SQL บน dayo local: `select count(*) from orders where source='pos' and pos_computed_total <> total_amount` แล้วส่งผลให้ agent อ่าน | ได้ 1 แถวพอดี (บิลเกินจำนวนครั้งจากขั้น 9) · มากกว่านั้นต้องตรวจทีละบิล |
| 11 | เพิกถอนกุญแจบนเว็บ แล้วตั้งกุญแจใหม่ที่หน้าสถานะแท็บเล็ต | ขึ้น "กุญแจเครื่องถูกยกเลิก" และรายชื่อพนักงานอัปเดตหลังตั้งกุญแจใหม่ (D136) |

## หลังผ่านทั้งหมด

- เปิด `API_V1_ENABLED=1` บน production (**เจ้าของกดเอง** ไม่ใช่ agent)
- deploy POS ตามขั้นตอน devops
- สำรองข้อมูลภายใน 24 ชม. และซ้อมกู้คืน 1 ครั้ง (ADR-0048 ข้อ 8)
- ทดสอบบนแท็บเล็ตจริงตามรายการในเอกสาร 09 (D51)
