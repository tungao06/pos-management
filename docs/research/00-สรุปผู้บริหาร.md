## 10 ข้อสรุปที่กำหนดทั้งโปรเจกต์

**1. iOS ปิดทางต่อเครื่องพิมพ์ผ่านเว็บทั้งหมด** ✅
Safari/iPadOS ไม่มี Web Bluetooth, WebUSB, Web Serial และเข้าถึงอุปกรณ์ใน LAN จากหน้า HTTPS ไม่ได้ ทุกเบราว์เซอร์บน iOS ใช้ WebKit — ลง Chrome ก็ไม่ช่วย

**2. Web Bluetooth รองรับเฉพาะ BLE ไม่รองรับ Bluetooth Classic (SPP)** ✅
เครื่องพิมพ์บลูทูธถูกๆ ที่ขายในไทยเป็น Classic เกือบทั้งหมด → **แม้บน Chrome Android เว็บแอปก็ต่อไม่ได้**

**3. ทางออก: เซิร์ฟเวอร์สร้าง ESC/POS + "print agent" ที่ร้านคอยดึงงานไปพิมพ์**
หน้าจอจะเป็น iPad, Android, มือถือ หรือคอมก็ได้หมด เปลี่ยนใจทีหลังไม่ต้องรื้อ

**4. ขนาด/ร้อน-เย็น = variant · ความหวาน/น้ำแข็ง = modifier ที่มีตัวคูณเป็นตัวเลข**
ข้อนี้กำหนดว่าระบบตัดสต็อกจะทำงานได้จริงหรือไม่ Loyverse ทำไม่ได้เพราะ modifier ไม่ตัดสต็อกเลย

**5. sync "รายการเคลื่อนไหว" ไม่ใช่ "ยอดคงเหลือ"**
บวกกับ insert อย่างเดียว + UUID จากเครื่อง → ปัญหา conflict หายไปเกือบหมด ไม่ต้องใช้ CRDT/PowerSync เขียน outbox เอง ~500–1,500 บรรทัดพอ

**6. Tag 29 ไม่มีเลขอ้างอิงกลับมา — นี่คือปัญหาใหญ่ที่สุดของ QR** ✅
QR พร้อมเพย์แบบโอนเข้าบัญชี (Tag 29) ต่อให้ใส่ยอดเงินแล้ว **ก็ไม่มีเลขที่ออเดอร์ส่งกลับมาให้เรา** → จับคู่ได้แค่ "ยอดเงิน + เวลา" ซึ่งพังทันทีที่ลูกค้า 2 คนจ่าย 65 บาทในนาทีเดียวกัน
→ ทางแก้: **ใช้บริการตรวจสลิปเพื่อให้ได้ `transRef`** หรือ **ใช้ Tag 30 (Bill Payment) ที่ใส่เลขออเดอร์ใน Ref1 ได้** (แต่ Tag 30 ต้องมี Biller ID ซึ่งต้องขอกับธนาคาร)

**7. บุคคลธรรมดาสมัคร Stripe และ Omise ได้จริง** ✅ (ยืนยันจากเอกสารทางการ)
ใช้แค่บัตรประชาชน + บัญชีธนาคารส่วนตัว ไม่ต้องจดบริษัท — แต่ **Omise มียอดขั้นต่ำ 20 บาท/รายการ** และ Bangkok Bank ระบุชัดว่า **"corporate users only"**

**8. ร้านที่ยังไม่จด VAT ไม่ต้องขออนุมัติ POS จากสรรพากรเลย** ✅
แต่ **ถ้าจด VAT แล้วจะออกใบกำกับภาษีอย่างย่อจากเครื่อง ต้องยื่น ภ.พ.06** และกฎที่ใช้อยู่ออกปี 2536 (ก่อนมีแท็บเล็ต) — เส้นแบ่งว่า "แอปบนแท็บเล็ต = เครื่องบันทึกการเก็บเงินหรือไม่" **ยังไม่ชัดในทางกฎหมาย**

**9. VAT 7% ต่ออายุถึง 30 ก.ย. 2570 แล้ว** ✅ (ครม. อนุมัติ 27 ก.ค. 2569)
เกณฑ์ 1.8 ล้านบาท/ปี ยังเหมือนเดิม ยืนยันโดยข่าวสรรพากร ปชส. 19/2569 (2 ส.ค. 2569)
→ **ห้าม hard-code เลข 7** ให้เก็บอัตราภาษีเป็น config ที่มีวันที่มีผล

**10. GrabFood มี API สาธารณะจริง แต่ LINE MAN ไม่มี** ✅
Grab มี SDK ทางการ 4 ภาษาที่ยัง maintain อยู่ (Go v1.0.4 ก.ค. 2026) — แต่ต้องขออนุมัติเป็น partner
LINE MAN ปิดสนิท หลักฐานชัดที่สุดคือ StoreHub (บริษัท POS มีเงินทุน) ยังต้องคีย์มือ
