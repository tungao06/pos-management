# ฮาร์ดแวร์และการพิมพ์

## 1. ตารางความสามารถของแพลตฟอร์ม ✅

| API | Chrome Android | Safari iPad/iPhone | Chrome เดสก์ท็อป |
|---|---|---|---|
| Web Bluetooth | ✅ (BLE เท่านั้น) | ❌ Apple ประกาศไม่มีแผนทำ | ✅ (BLE เท่านั้น) |
| Web Serial | ✅ Chrome 152+ | ❌ | ✅ Chrome 89+ |
| WebUSB | ✅ | ❌ | ✅ |
| เข้าถึง LAN จากหน้า HTTPS | ✅ Chrome 142+ (มี prompt) | ❌ | ✅ Chrome 142+ |
| ESC/POS ผ่าน TCP:9100 | ❌ เบราว์เซอร์ไม่มี raw socket | ❌ | ❌ |

**ทุกเบราว์เซอร์บน iOS ใช้ WebKit** — Chrome บน iPad ได้ผลเหมือน Safari เป๊ะ

**กับดักซ้อน:** Web Bluetooth = BLE/GATT เท่านั้น พูด Bluetooth Classic RFCOMM/SPP ไม่ได้ แต่เครื่องพิมพ์ ESC/POS บลูทูธราคาถูกในไทย (Xprinter, Rongta, Gprinter) เป็น Classic SPP เกือบทั้งหมด → เว็บแอปต่อไม่ได้แม้บน Android และต่อให้เจอรุ่น BLE ก็ยังติดปัญหา MTU เล็กและไม่มี flow control ทำให้ใบเสร็จยาวๆ พิมพ์เพี้ยน

## 2. ทางเลือกการพิมพ์จากเว็บ

**Epson ePOS-Print** — เครื่องพิมพ์รัน HTTP service เอง POST XML ไปที่
`http://<printer-ip>/cgi-bin/epos/service.cgi?devid=local_printer&timeout=10000`
⚠️ คู่มือ Epson เตือนเองว่าหน้า HTTPS พิมพ์ไม่ได้ (mixed content) และ **Epson ePOS SDK for JavaScript เวอร์ชันล่าสุด v2.27.0a ลงวันที่ 2 ต.ค. 2023 ระบุรองรับแค่ถึง Chrome 108 / Safari iOS 16 — ไม่อัปเดตมา 3 ปี** รองรับเฉพาะ LAN/Wi-Fi ไม่รองรับ Bluetooth/USB จากเบราว์เซอร์

**Star WebPRNT** — HTTP(S) POST ไปที่เครื่องพิมพ์ ใช้จาก iPad ได้ แต่ต้องมี SSL/TLS

**Star PassPRNT** — ทางออกของ iOS: เว็บเรียก URL scheme → iOS สลับไปแอป PassPRNT → พิมพ์ → กลับมา (เพิ่ม 1 แตะ ต้องลงแอป และไม่ได้สถานะเครื่องพิมพ์กลับมา)

**Star CloudPRNT** ⭐ — **เครื่องพิมพ์วิ่งไปดึงงานจากเซิร์ฟเวอร์เราเอง** ผ่าน HTTP POST เป็นระยะ ได้งานเป็น JSON และรายงานสถานะกลับ **ไม่ต้องใช้ API เบราว์เซอร์ ไม่ต้องลงแอปที่เครื่องลูกค้าเลย** รุ่นที่รองรับ: TSP143IV, mC-Print2/3, TSP743IIW, TSP847IIW (Epson มีของเทียบเท่าชื่อ Server Direct Print บนรุ่น TM-i)

**ไม่มีทาง AirPrint:** Epson TM-m30II ไม่รองรับ AirPrint → `window.print()` จาก iPad ไม่ถึงเครื่องพิมพ์ความร้อน

## 3. สถาปัตยกรรมที่แนะนำ ⭐

```
แท็บเล็ต (เบราว์เซอร์อะไรก็ได้) → เซิร์ฟเวอร์ (สร้าง ESC/POS) → คิวงานพิมพ์
                                                                    ↑ ดึงทุก 1-2 วิ
                                            print agent ที่ร้าน (กล่อง Android / Raspberry Pi)
                                                    ├── เครื่องพิมพ์ใบเสร็จ 80mm → ลิ้นชักเก็บเงิน (RJ11)
                                                    ├── เครื่องพิมพ์สติกเกอร์ติดแก้ว
                                                    └── (สำรอง) เครื่องพิมพ์บาร์
```

**ข้อดี:** หน้าจอเป็นอะไรก็ได้ · เพิ่มเครื่องที่ 2-3 ได้ฟรี · ไม่ต้องเขียนแอป native · เปลี่ยนแพลตฟอร์มทีหลังไม่ต้องรื้อ
**ต้นทุนเพิ่ม:** กล่อง Android ถูกๆ ~1,500–3,000 บาท + latency ~1–2 วินาที

## 4. ตารางตัดสินใจต่อแพลตฟอร์ม

| เป้าหมาย | BT Classic | USB | LAN 9100 | LAN HTTP | สรุป |
|---|---|---|---|---|---|
| **แอป Android native** | ✅ ทุกรุ่นรวมของถูก | ✅ USB Host | ✅ | ✅ | รองรับฮาร์ดแวร์กว้างสุด ถูกสุด |
| **แอป iOS native** | ⚠️ เฉพาะรุ่น MFi | ❌ | ✅ | ✅ | ต้องซื้อ Epson/Star เท่านั้น |
| **Chrome Android (PWA)** | ⚠️ BLE เท่านั้น | ✅ WebUSB | ❌ | ✅ | ใช้ได้แต่จำกัดฮาร์ดแวร์ |
| **Safari iPad (PWA)** | ❌ | ❌ | ❌ | ⚠️ ต้อง HTTPS จริง | **อย่าสัญญาว่าจะพิมพ์ผ่านบลูทูธได้** |

**PWA เก็บข้อมูลออฟไลน์บน iOS ✅** — Safari 17+ ให้โควตาถึง 60% ของดิสก์ต่อ origin **และเว็บแอปที่ Add to Home Screen ได้โควตาเท่าเบราว์เซอร์** WebKit ระบุเองว่าให้น้ำหนักกับ "เปิดเป็น Home Screen Web App" ตอนพิจารณา `navigator.storage.persist()`
→ **กฎ: ต้องบังคับ Add to Home Screen + ขอ persistent storage** ไม่งั้นคิวที่ยังไม่ sync อาจถูกลบเมื่อพื้นที่เต็มหรือไม่ได้ใช้นาน

## 7. กับดัก 6 ข้อที่ต้องเช็คก่อนจ่ายเงิน

1. **ภาษาไทยบนเครื่องพิมพ์ถูกๆ พิมพ์เพี้ยนได้จริง** — TIS-620/CP874 แต่ละรุ่นไม่เหมือนกัน สระบน/วรรณยุกต์วางผิดตำแหน่ง **ต้องขอลองพิมพ์ไทยจากรุ่นที่จะซื้อจริงก่อน** ทางที่ชัวร์ 100% คือเรนเดอร์ใบเสร็จเป็นรูปภาพแล้วสั่งพิมพ์เป็นรูป (ช้ากว่านิดหน่อยแต่ไม่มีวันเพี้ยน)
2. **80mm ไม่เอา 58mm** — 58mm ได้ 32 ตัวอักษร เครื่องดื่มที่มี 3–5 ตัวเลือกจะตัดบรรทัดจนอ่านไม่ออก / 80mm ได้ 48 ตัวอักษร เร็วกว่า (250–300 mm/s vs 90 mm/s) และ 58mm ส่วนใหญ่ในไทย**ไม่มีที่ตัดกระดาษอัตโนมัติ** ต่างกันแค่ 400–1,300 บาท
3. **ซื้อรุ่น LAN ไม่ใช่ Wi-Fi** — Wi-Fi บนเครื่องราคาถูกหลุดบ่อย และให้ตั้ง static DHCP reservation ให้เครื่องพิมพ์
4. **ลิ้นชักเปิดผ่านเครื่องพิมพ์เท่านั้น** — สาย RJ11/RJ12 เข้าพอร์ต DK สั่งด้วย ESC/POS `ESC p m t1 t2` **ไม่มีเครื่องพิมพ์ = ลิ้นชักไม่เปิด** และต้องเช็คว่าลิ้นชัก 12V หรือ 24V ตรงกับพอร์ต (24V เสียบพอร์ต 12V จะเปิดไม่แน่นอน)
5. **เครื่องสแกนต้องเป็น 2D** — QR พร้อมเพย์และ LINE เป็นโค้ด 2D เครื่องเลเซอร์ 1D อ่านไม่ได้ และถ้าจะสแกน QR **จากหน้าจอมือถือลูกค้า** ต้องเป็น CMOS imager ไม่ใช่เลเซอร์
6. **โหมดประหยัดแบตของแท็บเล็ตฆ่า sync worker และการเชื่อมต่อ BLE** — ต้องปิด battery optimization ทีละเครื่องตอนติดตั้ง และจอต้อง ≥10" ไม่งั้นบาริสต้ากดผิดตอนเร่ง

## 9. KDS หรือเครื่องพิมพ์บาร์?

⚠️ **ไม่มีผู้ขายไทยเจ้าไหนประกาศราคาฮาร์ดแวร์ KDS** — FoodStory/POSPOS/SilomPOS ขาย KDS เป็น add-on ซอฟต์แวร์ และคู่มือเลือกฮาร์ดแวร์ของ SilomPOS เองแนะนำเครื่องพิมพ์ครัว LAN ไม่ได้เสนอ KDS เป็นทางเลือกด้วยซ้ำ

| ทางเลือก | อุปกรณ์ | ราคา |
|---|---|---|
| **สติกเกอร์เป็นใบสั่ง** ⭐ | XP-420B + สติกเกอร์ | 2,288–3,988 + ฿43/700 ดวง |
| เครื่องพิมพ์บาร์ | Xprinter XP-Q80I LAN | 1,888 |
| KDS แท็บเล็ตถูก | Galaxy Tab A11 LTE + ที่ยึด | 6,291 + ~500 |
| KDS จอใหญ่ | ทีวี 24–32" + Android box | ~4,000–8,000 (ประมาณการ) |

**สำหรับร้านชานม 1 จุดขาย: เครื่องพิมพ์สติกเกอร์ชนะทั้งเครื่องพิมพ์บาร์และ KDS** เพิ่ม KDS เมื่อมี 2 เครื่องคิดเงินขึ้นไป
ถ้าทำ KDS: จอบาร์ดึงจาก `order_line WHERE station='BAR' AND fulfillment_status IN (QUEUED, MAKING)` แตะทีละบรรทัด บิลเป็น READY เมื่อทุกบรรทัดถูกแตะครบ → ได้ข้อมูล "ทำแต่ละแก้วนานเท่าไหร่" มาด้วย
