# คู่มือหน้าขาย: โปรโมชันที่เลือกเอง

สำหรับพนักงานและเจ้าของ · ข้อความปุ่มตรงกับหน้าจอในแผน 10 (ถ้าปุ่มบนจอไม่ตรง ให้แจ้งเจ้าของ)

## โปรมี 3 แบบ

| แบบ | ทำงานยังไง |
|---|---|
| อัตโนมัติ | ระบบใส่ให้เอง เมื่อบิลเข้าเงื่อนไข (วัน เวลา เมนู ช่องทาง) |
| รหัสโปร | พิมพ์รหัสในช่องรหัส ระบบแปลงเป็นตัวพิมพ์ใหญ่และตัดช่องว่างหัวท้ายให้ |
| เลือกเอง | พนักงานกดเลือกเอง (หัวข้อ "โปรโมชันที่เลือกเอง") |

## เลือกโปรที่เลือกเอง

1. ใส่เมนูลงตะกร้าก่อน
2. หาหัวข้อ **โปรโมชันที่เลือกเอง** บนหน้าขาย
3. กดปุ่มชื่อโปร ปุ่มจะถูกเลือก (กดซ้ำเพื่อเอาออก)
4. ดูส่วนลดในตะกร้าว่าตรงกับที่ต้องการ
5. ชำระเงินตามปกติ

หมายเหตุ:
- ปุ่มโปรจะโผล่เฉพาะโปรที่ใช้ได้กับบิลนี้ ณ ตอนนี้ (เวลา ช่องทาง เมนู)
- ถ้าไม่เห็นหัวข้อนี้เลย แปลว่าไม่มีโปรที่เลือกเองให้ใช้ หรือระบบกลาง (dayo) รุ่นนี้ยังไม่รองรับ
- เลือกได้ไม่เกิน **20 โปรต่อบิล**
- โปรที่เลือกไว้แล้วแต่หมดเวลา จะยังแสดงอยู่ เพื่อให้กดเอาออกได้

## ช่อง "เหตุผลที่เลือกโปรนี้เอง" ขึ้นเมื่อไหร่

ช่องเหตุผลไม่ขึ้นทุกครั้งที่เลือกโปร ขึ้นเฉพาะเมื่อ **ยอดบิลเหลือ 0 บาท และมีโปรที่เลือกเองอย่างน้อย 1 ตัว** (D133)

1. เห็นข้อความ "ยอดเหลือ 0 บาทและมีโปรที่เลือกเอง — ใส่เหตุผล 1–200 ตัวอักษรก่อนชำระ"
2. พิมพ์เหตุผลสั้น ๆ บรรทัดเดียว ยาว 1–200 ตัวอักษร (ช่องบอกจำนวน เช่น `12/200`)
3. กดชำระ

ถ้าไม่ใส่ จะชำระไม่ได้

ส่วนลดที่พิมพ์เองยังต้องมีเหตุผลเหมือนเดิม

## ป้าย "จำกัด n ครั้ง"

- ป้ายข้างชื่อโปร เช่น `จำกัด 10 ครั้ง` หรือ `จำกัด 3 ครั้ง/วัน`
- แปลว่าโปรนี้มีเพดานการใช้ ("ครั้ง" = 1 บิล)
- **แท็บเล็ตไม่นับให้** ป้ายมีไว้เตือนอย่างเดียว ไม่ห้ามกด
- ถ้าโปรครบจำนวนแล้วบนระบบกลาง บิลยังขายได้ แต่ระบบกลางจะติดธง "ยอดไม่ตรง" (`amount_mismatch`) ให้เจ้าของดูทีหลัง บิลแบบนี้ไม่ใช่ปัญหาการส่ง
- เจ้าของ: ดูบิลที่ติดธงได้ในหน้ารายละเอียดบิลบนเว็บ dayo

## บิลยอด 0 บาท

- ขายได้เฉพาะเมื่อ **โปรโมชันทำให้เป็น 0 บาท**
- รับชำระ **เงินสดเท่านั้น** (จะขึ้นข้อความ "บิลนี้ยอด 0 บาทจากโปรโมชัน — รับชำระด้วยเงินสดเท่านั้น")
- กด "ยืนยันรับเงินสด" ไม่ต้องรับเงินจริง
- ส่วนลดที่พิมพ์เอง ห้ามลดจนเหลือ 0 บาท (ต้องน้อยกว่ายอดรวม)
- ถ้าจะให้ฟรีทั้งบิล ต้องใช้โปร ไม่ใช่พิมพ์ส่วนลด

## บรรทัดส่วนลดต่อแก้ว

- ใต้เมนูที่ได้ลด ในตะกร้า จะมีบรรทัด เช่น `ลด ฿5.00/แก้ว`
- ถ้าลดหลายโปร ระบบแสดงส่วนลดแยกตามโปร
- ตัวเลขนี้คือส่วนลดต่อ 1 แก้ว คูณจำนวนแก้วได้ยอดลดของรายการนั้น
- บันทึกไว้กับบิลแบบแช่แข็ง ดูย้อนหลังได้ว่าแก้วไหนลดจากโปรอะไร

## เจอปัญหา

| อาการ | ทำอะไร |
|---|---|
| ไม่เห็นโปรที่เลือกเอง | เช็กเวลา/ช่องทางของโปร · ต่อเน็ตแล้วกด "ส่งตอนนี้" ที่หน้าสถานะระบบ (ดึงเมนูใหม่) · ถ้ายังไม่เห็น แจ้งเจ้าของ |
| แถบ "ระบบกลางมีโปรรุ่นใหม่กว่าแอปนี้" | อัปแอปเป็นรุ่นล่าสุด (โปรใหม่จะยังไม่ถูกใช้จนกว่าจะอัป) |
| ส่งบิลแล้วขึ้น "เหตุผล" ไม่ผ่าน (`reason_required`) | เป็นบั๊กเครื่อง แจ้งเจ้าของ ห้ามลองซ้ำ · เจ้าของยกเว้นบิลได้ที่หน้า "ส่งไม่ผ่าน" |
| ราคาต่างจากที่คิดไว้หลังส่งบิล | ดูธง "ยอดไม่ตรง" บนเว็บ dayo · มักเกิดเมื่อโปรครบจำนวนครั้งบนระบบกลาง |
